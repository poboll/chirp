chirp. 报信小鸟

一只住在菜单栏的小鸟，把你正在用的软件报到博客上。

纯 AppKit · 零第三方依赖 · release 二进制约 200KB · 开机自启

GitHub 仓库 ↗ 使用方式 ↓

01它长这样

02它做什么

切换应用 ──防抖 3s──▶ POST /api/v3/fn/ps/update {key, timestamp, process: {name, iconUrl?}} │ ▼ mx-space snippet 缓存 5 分钟 + WebSocket 广播 │ ▼ 博客导航栏「正在使用 XX」（Shiro / Yohaku 主题）

轻纯 AppKit + Swift Package，零第三方依赖，无 Dock 图标，只住菜单栏。
省只在应用切换时上报（3 秒防抖），每 4 分钟心跳续期，失败时小鸟变红。
稳睡眠唤醒自动补报，LaunchAgent KeepAlive 常驻，配置损坏绝不覆盖。
图标三层主题内置映射 → app-icons CDN → data URI 兜底，新装软件零操作。

03使用方式

1

克隆并构建

macOS 13+，只需 Xcode Command Line Tools：

git clone https://github.com/poboll/chirp.git
cd chirp
sh scripts/build-app.sh            # 构建 + 组装 + 安装到 /Applications
2

写配置

准备 mx-space 的 ps/update fn snippet（Shiro 官方生态自带，主题配置 module.activity.endpoint），然后：

mkdir -p ~/.config/chirp
cat > ~/.config/chirp/config.json <<'EOF'
{
  "endpoint": "https://your-blog.example.com/api/v3/fn/ps/update",
  "key": "与 snippet 一致的密钥",
  "debounceSeconds": 3,
  "heartbeatSeconds": 240
}
EOF
chmod 600 ~/.config/chirp/config.json
3

设为开机自启

安装 LaunchAgent 并立即运行，菜单栏出现小鸟即成功：

sh scripts/install-launch-agent.sh    # 开机自启动 + 立即运行

04配置项

字段默认说明
endpoint必填ps/update fn snippet 的完整地址
key必填与 snippet 一致的密钥（文件权限请保持 600）
debounceSeconds3应用切换防抖，避免频繁切换时刷屏
heartbeatSeconds240心跳续期间隔（服务端缓存 5 分钟，需小于它）
iconManifestUrlapp-icons CDN应用名 → 图标的映射清单，每日自动刷新
iconBaseapp-icons CDN图标 URL 前缀；未命中时自动回落 data URI
